VALKYRYS APP - desktop app

Build it once (needs internet, a few minutes):
 1. Install Node.js (LTS) from https://nodejs.org  (only needed for building).
 2. Double-click BOUWEN.bat.
 3. Open the "dist" folder and run the installer, or use the portable .exe directly.

The finished app is a normal Windows program with its own window and icon. It needs no browser, no Claude and no internet.

Your data (numbering, history, settings) is in:  %APPDATA%\Valkyrys app\data.json
(the older "Valkyrys Facturen" kept its data in %APPDATA%\Valkyrys Facturen: the app moves that folder along on its first start, so your numbering carries over).
Windows SmartScreen may warn about an unknown app the first time: More info > Run anyway.
